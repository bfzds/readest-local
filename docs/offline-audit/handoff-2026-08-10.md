Task 2 具体删除：

- `src/services/` 下的 `ai`、`bookorbit`、`hardcover`、`metadata`、`novel`、`opds`、`readwise`、`reedy`、`rss`、`send`、`sync`、`translators`、`wordlens` 整目录。

- `src/utils/discord.ts`、`src/utils/cover.ts`、`src/app/reader/hooks/useReadwiseSync.ts`。
- Library 云组件：`TransferQueuePanel`、`ShareBookDialog`、`ImportFromUrlDialog`、`ImportNovelDialog`、`OPDSDialog`、`feeds/*`。
- 约 180 个云相关测试；保留测试中残留的云模块 mock 已清理。

关键行为改动：

- `AppService` 接口删除云上传/下载/副本方法；`appService.ts` 不再引用 `cloudService`、`sync`、`rss`。
- `deleteBook` 改为纯本地实现（在 `bookService.ts`），保留“managed 文件可删、external 原文件不删”的安全语义。
- `fetchBookDetails` 不再尝试云端下载，文件缺失时抛 `BookFileNotFoundError`。
- `runMigrations` 移除 20260706 云同步自动启用迁移。
- `reader/page.tsx` 移除共享链接 hook；`FoliateViewer` / `ReaderContent` 移除 Discord；`ExportMarkdownDialog` 不再发布公开封面；`Annotator` 移除 Readwise。
- `TabNavigation` 修复删除 AI 标签后遗留的 JSX 语法错误。

- Windows PowerShell；仓库路径含中文 `C:\Users\30575\Documents\阅读器`。
- `apply_patch` 对含非 ASCII 的行匹配不可靠；小改动优先用 Node REPL 做精确字符串替换，文件多为 CRLF，写回时保持 CRLF。
- `pnpm` registry 已设置为 npmmirror；下载依赖优先国内镜像。
- 不使用 Codex 内置浏览器访问/调试/验证本地项目。
