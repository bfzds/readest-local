- `TabNavigation` 修复删除 AI 标签后遗留的 JSX 语法错误。

## 环境与操作约束

- Windows PowerShell；仓库路径含中文 `C:\Users\REDACTED_USER\Documents\阅读器`。
- `apply_patch` 对含非 ASCII 的行匹配不可靠；小改动优先用 Node REPL 做精确字符串替换，文件多为 CRLF，写回时保持 CRLF。
- `pnpm` registry 已设置为 npmmirror；下载依赖优先国内镜像。
- 不使用 Codex 内置浏览器访问/调试/验证本地项目。
- 不使用破坏性 git 命令；不撤销用户已有改动。
- 上下文控制：不用 `Get-Content -Raw` 读大文件；先列目录、再 `rg` 定位、再小段读取。
