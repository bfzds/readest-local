# 阅读界面可交互按钮清单

> 统计范围：阅读书籍页面（顶栏、底栏、阅读正文区、侧边栏、笔记本栏、朗读/速读/段落/自动滚动等特殊模式，以及从阅读页可达的弹窗）。
> 数据来源：`apps/readest-app/src` 阅读页相关组件源码静态核对。
> 统计时间：2026-08-11。

## 1. 总体说明

1. 本清单把“同一功能在不同平台/入口的重复按钮”合并为一条，并在“出现状态”里注明平台差异。
2. 该应用没有独立的“截图”按钮；分享能力通过“选中文字后的操作条 → 分享”实现。
3. 亮度调节、夜间模式、字号调整在桌面端主要位于“视图选项/设置对话框”，移动端则位于底部“颜色/字体”面板。
4. “隐藏建议”里的“可隐藏”不等于“删除功能”，更合理的做法是折叠进菜单、移入设置，或仅在小屏上收起。

## 4. 隐藏优先级建议

优先级按“隐藏后对普通用户的影响”排序：

1. **高优先级隐藏（低影响）**：同步子项、RSVP/段落模式/自动滚动控制条、关于/快捷键帮助、书菜单、搜索历史、批注过滤面板。这些属于低频功能或高级模式，普通用户很少触达；隐藏后建议保留入口（菜单项）而非删除功能。
2. **中优先级隐藏（中影响）**：下拉书签手势、行距/页边距滑块、快捷批注下拉、固定/取消固定侧边栏/笔记本、设置搜索/设置菜单。这些有替代路径，但移除后对应能力会多一步操作。
3. **低优先级隐藏（高影响）**：翻页、进度滑块、页码跳转、目录、书签开关、亮度/夜间模式、字号、TTS 主入口、分享/高亮。隐藏会直接削弱核心阅读体验，不建议隐藏。

## 5. 需要注意

1. 本文档只统计“阅读界面内可交互按钮”，不包含书架页、系统设置全局页面中的完整按钮体系。
2. 标注为“可隐藏”的按钮，建议优先采用“折叠进更多菜单/设置”而不是彻底移除，避免功能缺失。
3. 桌面端与移动端按钮集合不同：移动端依赖底部面板，桌面端依赖顶栏/底栏和侧边栏；实际裁剪时应按平台分别评估。
